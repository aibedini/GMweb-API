# Fix: linked web composer and contact layout

The Contacts view now renders compact full-width rows with an SMS action indicator. Compose opens a bounded local contact picker and permits a typed number. A new contact's composer is anchored below the empty conversation area. Existing conversation matching uses exact title/subtitle equality. The linked PWA no longer calls the dashboard-only push-subscriptions route. The key banner reports the stored error. The existing two-second key-work deadline remains in place so a stalled key endpoint cannot block ciphertext catch-up.

No SMS is submitted by selecting a contact. The existing `SEND_MESSAGES` capability and encrypted durable command path are unchanged.
